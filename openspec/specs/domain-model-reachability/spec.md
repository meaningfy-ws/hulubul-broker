## Requirements
### Requirement: Generated domain models are importable from the hulubul package
LinkML-generated Pydantic domain models SHALL be written to a location inside the installed
`hulubul` package (`hulubul/core/models/domain/`), so any bounded context can import them
via a normal Python import, without a `sys.path` modification.

#### Scenario: A bounded context imports a domain model directly
- **WHEN** code anywhere under `hulubul/` writes
  `from hulubul.core.models.domain.hulubul_models import Channel, Medium`
- **THEN** the import succeeds with no `sys.path` manipulation, in both application code and
  test code

### Requirement: Generated domain models are never hand-edited
The generated domain package SHALL be clearly marked as generated content, consistent with
`model/generated/`'s existing "never hand-edit" convention, and SHALL be regenerated only via
`make pydantic`.

#### Scenario: The package declares its generated status
- **WHEN** a developer opens `hulubul/core/models/domain/__init__.py`
- **THEN** it states the content is generated by `make pydantic` from `model/linkml/` and
  must not be hand-edited

#### Scenario: Regenerating overwrites the file deterministically from the same source
- **WHEN** `make pydantic` is run
- **THEN** `hulubul/core/models/domain/hulubul_models.py` is fully overwritten from
  `model/linkml/hulubul.yaml`, with no manual merge step required

### Requirement: Only the pydantic generation target relocates
Relocating the Pydantic output SHALL NOT change the output or location of any other LinkML
generation target (OWL, SHACL, JSON Schema, diagrams, Cypher, neomodel), and SHALL NOT modify
`model/linkml/` schema content.

#### Scenario: Non-pydantic generated artifacts are unaffected
- **WHEN** `make all` is run after this change
- **THEN** `model/generated/owl/`, `model/generated/shacl/`, `model/generated/jsonschema/`,
  `model/generated/diagrams/`, `model/generated/neo4j/`, and `model/generated/neomodel/` are
  written exactly as before, unaffected by the pydantic target's new output path
