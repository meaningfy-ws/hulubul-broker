# Security Policy

## Reporting a Vulnerability

Report suspected security vulnerabilities privately to **eugen@meaningfy.ws**.
Do not open a public GitHub issue for security reports.

Include, where possible:
- A description of the vulnerability and its potential impact.
- Steps to reproduce, or a proof of concept.
- The affected version/commit.

You should receive an acknowledgement within 5 business days. We aim to
provide a remediation timeline once the report is triaged.

## Supported Versions

This project has not yet reached a stable `1.0.0` release; security fixes
are applied to the `main`/`develop` branches only, not backported.

## Scope

Automated secret scanning for this repository is provided at the
organization level (SonarQube, Snyk, GitHub secret scanning) rather than by
an in-repo scanner.
